# 7-Zip 확장 메뉴

Windows 탐색기와 파일관리자의 기존 우클릭 메뉴에 압축·해제 기능을 추가하는 독립적인 확장 프로그램입니다. 원래 7-Zip·반디집 메뉴는 유지합니다. 현재 개발 버전은 **0.4.3**이며, 공개 배포 버전은 **0.4.2**입니다.

Windows 11 탐색기에서는 **더 많은 옵션 표시** 안에서 사용합니다.

## 다운로드와 요구 사항

[v0.4.2 릴리스](https://github.com/igedaena/7zipcontextmenu/releases/tag/v0.4.2)에서 설치 EXE 또는 포터블 ZIP을 받으세요. 함께 제공하는 `SHA256SUMS.txt`로 해시를 확인할 수 있습니다.

- Windows x64. 설치 프로그램의 최소 OS 조건은 Windows 10 1809입니다.
- **7-Zip 26.05 이상**, **.NET Framework 4.8 이상**이 별도로 필요합니다.
- 7-Zip과 .NET은 배포물에 포함하지 않으며 자동 설치하지 않습니다.
- 사용 PC에는 Visual Studio, CMake, Windows SDK가 필요하지 않습니다. 현재 배포 EXE에는 코드 서명이 없습니다.

## 설치형

1. `SevenZipExtension-Setup-0.4.2.exe`를 실행합니다. 설치에는 관리자 승인이 필요합니다.
2. 기본 위치인 `C:\Program Files\SevenZipContextMenu`에 설치하고 모든 사용자의 메뉴를 등록합니다.
3. 메뉴가 갱신되지 않으면 사용 중인 파일관리자를 닫고 다시 실행합니다.

제거는 **Windows 설정 → 앱 → 설치된 앱 → 7-Zip 확장 → 제거**를 사용합니다. 제거에도 관리자 승인이 필요하며 개인 옵션은 보존합니다.

## 포터블

1. `SevenZipExtension-Portable-0.4.2.zip`을 계속 사용할 폴더에 모두 풉니다.
2. **메뉴 등록.cmd**를 일반 권한으로 실행합니다.
3. **설정 열기.cmd** 또는 사용자 시작 메뉴의 **7-Zip 확장 (포터블)**에서 옵션을 엽니다.
4. 사용을 끝낼 때는 **메뉴 해제.cmd**를 먼저 실행합니다. 파일관리자를 닫아 DLL 사용이 끝난 뒤 폴더를 삭제할 수 있습니다.

관리자 승인 없이 현재 사용자의 HKCU에 메뉴와 COM 경로를 등록합니다. 폴더를 옮기면 새 위치에서 다시 등록하세요. 개인 옵션과 작업 목록은 각 PC의 사용자 영역에 남으므로 USB 폴더와 함께 자동으로 이동하지 않습니다.

설치형과 포터블은 동시에 등록하지 않습니다. 공용 설치가 있으면 먼저 Windows 앱 목록에서 제거하세요. 설치형으로 돌아갈 때도 포터블 메뉴를 먼저 해제합니다. 다른 소유자의 등록은 덮어쓰지 않습니다.

## 주요 기능

| 기능 | 동작 |
| --- | --- |
| 알아서 풀기 | 최상위 항목이 하나면 압축 파일 옆에 꺼내고, 여러 개면 압축 파일명 폴더에 풉니다. 여러 압축 파일도 각각 판단합니다. |
| 파일명 폴더에 풀기 | 압축 파일명 폴더 안에 원래 구조대로 풉니다. |
| 각각 ZIP / 7z 압축 | 선택한 파일·폴더마다 별도의 압축 파일을 만듭니다. |
| "이름.zip" / "이름.7z" 에 추가 | 생성될 압축 파일명을 표시합니다. 긴 이름은 메뉴에서만 중간을 `...`로 줄이며 확장자·충돌 번호와 실제 파일명은 유지합니다. 여러 선택 항목은 하나로 묶습니다. |
| 압축 파일을 선택해 새 압축에 추가 | 원본 압축 파일을 그대로 새 압축 파일 안에 담으며 형식 변환은 하지 않습니다. 같은 이름이 있으면 새 이름을 표시합니다. |
| 7-Zip 기본 기능 | 열기, 형식 지정 열기, 압축 풀기·추가 대화상자, 여기에 압축 풀기, 검사, CRC/SHA를 연결합니다. |

확장의 압축·해제는 결과 이름이 겹치면 `(2)`, `(3)`을 붙여 기존 항목을 보존합니다. 7-Zip 대화상자의 작업은 사용자가 선택한 7-Zip 옵션을 따릅니다.

압축·해제의 실제 진행률, 속도, 남은 시간과 암호 입력은 **7-Zip 기본 진행 창**에서 확인합니다. 알아서 풀기·파일명 폴더에 풀기·각각 압축하기도 같은 창을 사용합니다. 매우 짧은 작업은 창이 보이기 전에 끝날 수 있습니다. 여러 항목이나 TAR.GZ 같은 복합 해제는 파일·단계별로 순서대로 진행하므로 전체 묶음의 통합 진행률은 아닙니다. 오류·취소 시 결과를 안내하며, 일부 실패와 취소 전에 완료된 결과는 유지합니다.

## 옵션

우클릭의 **7-Zip 확장 설정…** 또는 시작 메뉴의 **7-Zip 확장 설정**을 엽니다.

- 기능별 ON/OFF, 바로 표시 / 계단식 표시, 메뉴 아이콘을 설정합니다.
- ‘압축파일 열기’는 지원하는 압축 확장자의 파일 하나를 선택했을 때 표시합니다. ‘형식을 지정해 열기’는 일반 파일 하나에도 표시하여 형식을 직접 지정할 수 있습니다.
- 한 목록에서 항목을 선택하고 **위로 ↑ / 아래로 ↓**로 순서를 편집합니다. 설정 목록과 실제 메뉴의 순서가 같으며 체크를 꺼도 위치는 유지합니다.
- **구분** 열에서 ‘7-Zip 기본’(기본 기능 연결)과 ‘확장’(알아서 풀기·파일명 폴더에 풀기·각각 압축의 추가 처리)을 확인할 수 있습니다. 구분은 설정 창에만 표시합니다.
- 형식 선택과 CRC/SHA는 하위 메뉴 단위로 이동하며 설정 항목은 항상 맨 아래에 표시합니다. **기본 순서 복원**은 순서만, **기본값 복원**은 표시 옵션과 순서를 함께 되돌립니다.
- 파일·폴더 하나를 선택하고 같은 형식의 ‘이름으로 압축하기’와 ‘에 추가’를 모두 켜면, 실제 파일명이 보이는 ‘에 추가’만 표시합니다. 한쪽만 켜면 해당 기능을 표시하며, 다중 선택에서는 각각 압축과 하나로 압축을 구분해 표시합니다. 체크와 저장된 순서는 유지합니다.
- 우클릭 설정 항목을 숨겨도 시작 메뉴나 포터블의 **설정 열기.cmd**로 다시 열 수 있습니다.
- 적용은 저장, 확인은 저장 후 닫기, 취소는 마지막 적용 이후의 편집 취소입니다. 기본값 복원도 적용·확인 후 저장합니다.
- 다음 우클릭부터 반영합니다. Windows 11에서는 바로 표시도 기존 메뉴 안에 표시됩니다.

개인 옵션은 `HKCU\Software\SevenZipContextMenu`의 `OptionsV1`, 메뉴 순서는 `MenuOrderV1`에 저장하며 설치형과 포터블이 공유합니다. 기존 표시 옵션은 유지하며 저장된 순서가 없으면 공통 기본 순서를 사용합니다. 메뉴·압축·해제·설정은 일반 사용자 권한으로 실행합니다. 관리자 권한으로 실행한 파일관리자와 설정 앱에서는 작업을 차단합니다.

## 지원 범위와 제한

압축 생성은 ZIP·7z를 지원합니다. 해제는 설치된 7-Zip을 사용하며 ZIP, 7z, RAR, TAR 및 GZ/BZ2/XZ 계열, 분할 압축을 처리합니다. TAR.GZ 등은 중간 TAR까지 풀어 최종 내용을 꺼냅니다. 분할 압축은 필요한 볼륨을 같은 폴더에 두세요.

알아서 풀기는 같은 드라이브의 임시 폴더에 먼저 해제하므로 압축 파일이 있는 폴더의 쓰기 권한과 충분한 공간이 필요합니다. 강제 종료나 권한 문제로 `.7ze-work-...` 폴더가 남을 수 있습니다. 암호는 입력창에서 받고 명령행·작업 목록·결과 파일에 기록하지 않습니다.

링크·연결 지점이 포함된 입력 폴더와 해제 결과는 지원하지 않습니다. 네트워크 경로, 긴 경로 및 일부 특수 형식은 추가 검증이 필요합니다. Windows 11 기본 간소화 메뉴 통합은 제공하지 않습니다.
