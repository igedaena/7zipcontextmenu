7-Zip 확장 0.4.2 포터블

1. ZIP을 보관할 폴더에 모두 풉니다.
2. 메뉴 등록.cmd를 일반 권한으로 실행합니다.
3. 설정 열기.cmd 또는 시작 메뉴의 7-Zip 확장 (포터블)에서 옵션을 설정합니다.
4. 제거할 때는 메뉴 해제.cmd를 먼저 실행합니다.
5. 파일관리자를 종료하여 DLL 사용이 끝난 뒤 포터블 폴더를 삭제할 수 있습니다.

설치 EXE와 관리자 승인은 필요하지 않습니다. 프로그램은 압축을 푼 폴더에서 실행합니다.
우클릭 통합을 위해 현재 사용자 HKCU에 COM/메뉴 경로를 등록하고 사용자 시작 메뉴에 설정 바로 가기를 만듭니다.
메뉴 해제는 이 포터블이 소유한 등록과 설정 바로 가기만 제거합니다.
Program Files와 HKLM에는 쓰지 않고 기존 7-Zip·반디집 메뉴를 변경하지 않습니다.

폴더를 옮긴 경우 새 위치에서 메뉴 등록.cmd를 다시 실행합니다.
다른 PC에서도 한 번 등록해야 합니다. 완전히 레지스트리를 사용하지 않는 형태는 아닙니다.
개인 옵션과 작업 목록은 각 PC의 사용자 영역에 저장합니다. USB 폴더로 설정이 자동 이동하지 않습니다.
같은 사용자 계정에서는 설치형과 포터블이 같은 개인 옵션을 사용합니다.

공용 설치 버전과 동시에 등록할 수 없습니다. 기존 버전을 Windows 앱 목록에서 제거한 뒤 등록하세요.
포터블에서 설치형으로 바꿀 때도 메뉴 해제.cmd를 먼저 실행한 뒤 설치하세요.
기존 개발용 또는 다른 사용자 등록이 있으면 자동으로 덮어쓰지 않습니다.
메뉴가 갱신되지 않으면 사용 중인 파일관리자를 종료한 뒤 다시 실행해 주세요.
탐색기에서는 기존 메뉴인 더 많은 옵션 표시 안에서 사용합니다.
DLL이 사용 중이면 폴더 삭제가 잠길 수 있습니다. 파일관리자를 강제 종료하지 않습니다.

별도 필요: Windows x64, 7-Zip 26.05 이상, .NET Framework 4.8 이상.
7-Zip과 .NET은 이 ZIP에 포함되어 있지 않으며 자동 다운로드하지 않습니다.
관리자 권한으로 실행한 파일관리자나 설정 앱에서는 작업을 차단합니다.

기능은 설치 버전 0.4.2와 같습니다.
- 기능별 ON/OFF, 바로/계단식 표시, 아이콘, 우클릭 설정 메뉴 숨김
- 알아서 풀기, 파일명 폴더에 풀기, 각각 ZIP·7z 압축
- 7-Zip 열기·해제·테스트·추가 대화상자, CRC/SHA
- 빠른 압축은 "생성될 이름.zip" / "생성될 이름.7z" 에 추가로 표시
- 압축 파일을 추가하면 원본을 새 압축 안에 담으며 형식을 변환하지 않음

등록 해제 후에도 개인 옵션은 보존됩니다.
