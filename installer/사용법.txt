7-Zip 확장 0.4.2

FreeCommander XE 또는 탐색기의 기존 우클릭 메뉴에서 사용하세요.
탐색기에서는 ‘더 많은 옵션 표시’ 안에 있습니다.

설정 열기:
- 우클릭 > 7-Zip 확장 > 7-Zip 확장 설정…
- 시작 메뉴 > 7-Zip 확장 > 7-Zip 확장 설정
- 실행기 SevenZipContextWorker.exe --settings

기능별 체크 ON/OFF, 바로 표시/계단식 표시, 메뉴 아이콘을 설정합니다.
설정은 현재 사용자에게 저장하며 관리자 승인이 필요하지 않습니다.
적용 후 우클릭 메뉴를 다시 열면 반영합니다.
설정 화면에서 우클릭 설정 메뉴의 표시 체크를 끄면 설정 항목을 숨깁니다.
숨긴 뒤에도 시작 메뉴에서 설정을 열 수 있습니다.
모든 기능과 설정 메뉴를 함께 끄면 확장 메뉴 전체가 사라집니다.
기본값 복원은 적용 또는 확인 버튼을 눌러야 저장됩니다.
취소는 마지막 적용 이후의 편집을 버립니다.

기본값으로 제공하는 기존 기능:
- 알아서 풀기 / 각각 알아서 풀기
- 파일명 폴더에 풀기 / 각각 파일명 폴더에 풀기
- 이름으로 ZIP·7z 압축하기 / 각각 이름으로 ZIP·7z 압축하기

선택해서 추가하는 기본 기능:
- 압축파일 열기, 형식을 지정해 열기
- 압축 풀기 대화상자, 여기에 압축 풀기, 테스트
- 압축파일에 추가 대화상자
- "생성될 이름.zip" / "생성될 이름.7z" 에 추가 (여러 선택 항목은 하나로)
- CRC/SHA 및 SHA256 체크섬 파일 생성/검증

원래 7-Zip·반디집 메뉴는 유지합니다. 이메일 명령은 제공하지 않습니다.
‘바로 표시’도 Windows 11 탐색기에서는 기존 메뉴 안에 표시합니다.
기본 열기·대화상자·체크섬은 설치된 7-Zip의 창을 사용합니다.

기존 확장 압축·해제와 하나로 압축하기는 결과 이름이 겹치면
(2), (3)을 붙여 새로 만들고 기존 결과를 보존합니다.
여기에 압축 풀기는 기존 파일을 보존하도록 7-Zip의 새 이름 해제를 사용합니다.
7-Zip 대화상자의 작업은 사용자가 선택한 7-Zip 옵션을 따릅니다.
압축 파일이 있는 폴더에 임시 작업 공간과 쓰기 권한이 필요합니다.
확장의 기존 압축·해제는 링크·연결 지점을 지원하지 않습니다.
네트워크·긴 경로 등의 별도 확인이 필요한 제한은 프로젝트 README를 참조하세요.

제거: Windows 설정 > 앱 > 설치된 앱 > 7-Zip 확장 > 제거
개인 메뉴 설정은 제거 후에도 보존합니다.

빠른 압축은 "생성될 이름.zip" / "생성될 이름.7z" 에 추가로 표시합니다.
여러 항목은 하나로 묶으며, 압축 파일을 선택하면 원본을 새 압축 안에 담습니다.
형식 변환이 아니며, 기존 이름이 있으면 (2), (3)으로 다른 이름을 사용합니다.

7-Zip 26.05 이상 및 .NET Framework 4.8 이상이 별도로 설치되어 있어야 합니다.
프로그램과 7z.dll의 버전을 설치 시와 실행 시에 확인합니다.
관리자 권한으로 실행한 파일관리자 또는 설정 앱에서는 작업을 차단합니다.
파일관리자와 설정 앱을 일반 권한으로 다시 실행해 주세요.
Visual Studio, Windows SDK, CMake, Visual C++ 재배포 패키지는 필요하지 않습니다.
Windows x64 공용 설치용이며 설치·제거 시 관리자 승인이 필요합니다.
작업 목록은 사용자별 AppData\Local\SevenZipContextMenu\Requests에 저장합니다.
