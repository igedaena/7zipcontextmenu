# 0.4.3 — 로컬 개발 빌드

2026-10-30. 공개 배포 전이며 GitHub 릴리스는 0.4.2를 유지합니다.

- 빠른 ZIP/7z 압축 메뉴의 파일명이 60자를 넘으면 앞 34자와 뒤 23자를 남기고 중간을 `...`로 줄입니다. UTF-16 서로게이트 쌍을 나누지 않으며 `.zip`/`.7z`와 충돌 번호를 유지합니다. 실제 출력 이름·경로·압축 동작은 바꾸지 않습니다.
- 설정 창의 체크 목록을 하나로 합치고 **7-Zip 기본 / 확장** 구분 열을 추가했습니다. 파일명 폴더에 풀기는 기존 결과 보존 등 확장 처리를 사용하므로 ‘확장’으로 표시합니다.
- **위로 / 아래로**로 항목 순서를 편집하고 **기본 순서 복원**으로 되돌릴 수 있습니다. 꺼 둔 항목의 위치도 저장하며 실제 메뉴는 해당 선택에 맞는 항목만 같은 순서로 표시합니다.
- 형식 지정 열기와 CRC/SHA는 묶음 단위로 이동하며 내부 순서는 유지합니다. 설정 항목은 맨 아래에 둡니다. 바로 표시와 계단식 표시 모두 같은 순서를 사용합니다.
- 기존 `OptionsV1` 체크·배치·아이콘 옵션을 유지하며 `MenuOrderV1`에 사용자 순서를 별도로 저장합니다. 알 수 없는 항목·중복은 무시하고 누락 항목은 기본 순서로 보충합니다. 잘못된 형식·지나치게 큰 값은 기본 순서를 사용합니다.
- 단일 파일·폴더에서 같은 형식의 각각 압축과 빠른 압축이 모두 켜져 있으면 실제 출력 이름이 보이는 빠른 압축만 표시합니다. ZIP/7z를 각각 판단하며 한쪽만 켜진 경우와 다중 선택은 유지합니다. 표시만 조정하며 저장된 체크·순서와 실제 압축 동작은 바꾸지 않습니다.
- ‘압축파일 열기’는 기존 압축 확장자 판별을 통과한 파일 하나에만 표시합니다. 일반 파일·폴더·다중 선택에서는 숨기며, 별도 ‘형식을 지정해 열기’의 단일 파일 동작은 유지합니다.

검증: x64/Win32 Release 빌드, 옵션·메뉴 594개 시나리오와 설정 창 저장·취소·복원·화면 배치, 기존 통합 26개, 포터블 격리 35개 통과. 일반 파일·폴더·다중 선택에서 기본 열기 숨김, 압축 파일 단일 선택에서 표시, 형식 지정 열기와의 독립 체크를 확인했습니다. 단일 선택의 압축 중복 제거와 기능별 ON/OFF·다중 선택·사용자 순서 조합을 확인했습니다. 긴 한글·이모지·`&` 이름의 메뉴 축약 및 실제 ZIP/7z 출력 이름 보존을 확인했습니다. 최종 바이너리·두 패키지의 Kaspersky 검사에서 내부 포함 33개 모두 정상, 탐지·의심·오류 0입니다. 실제 설치·공용 메뉴 등록은 변경하지 않았으며 실제 설치·제거 순환과 UAC 상승 검사는 이번에 반복하지 않았습니다.

# 0.4.2

2026-10-27. 기본 7-Zip 진행 창과 메뉴 용어를 맞췄습니다.

- 알아서 풀기, 파일명 폴더에 풀기, 각각 ZIP/7z 압축과 빠른 압축에 **7-Zip 기본 진행 창**을 사용합니다. 진행률·속도·남은 시간 및 암호 입력·취소를 7-Zip에서 처리합니다.
- 실제 진행률 없이 막대만 움직이던 확장 진행 창과 별도 암호 창을 제거했습니다. 오류·취소 시에는 확장이 완료·실패 결과를 안내합니다.
- 빠른 압축은 단일 파일·폴더·압축 파일·다중 선택 모두 **"실제 생성될 이름.zip" / "실제 생성될 이름.7z" 에 추가**로 표시합니다. 이름이 겹치면 (2), (3)으로 다른 이름을 사용합니다. 압축 파일을 선택하면 원본 파일을 새 압축에 담는 동작이며 형식 변환이 아닙니다.
- **여기에 압축 풀기**로 7-Zip 기본 용어를 맞췄습니다. **파일명 폴더에 풀기 / 각각 파일명 폴더에 풀기**, **알아서 풀기 / 각각 알아서 풀기**는 유지합니다. 설정 창 명칭도 함께 정리했습니다.
- 임시 해제 후 결과 배치, 기존 파일 보존, TAR.GZ 등의 중간 TAR 해제, 분할 볼륨 중복 제거 및 개인 옵션 호환을 유지합니다.

여러 파일과 복합 압축은 파일·단계별로 순서대로 진행합니다. 표시되는 진행률은 해당 7-Zip 작업 기준이며 전체 묶음의 통합 진행률은 아닙니다. 짧은 작업은 창이 나타나기 전에 끝날 수 있습니다.

## 검증

- x64/Win32 Release 빌드 및 메뉴·옵션 114개 시나리오, 기존 통합 26개 통과.
- 실제 7-Zip GUI 검사 25개: ZIP/7z 생성, 진행 컨트롤, 암호 입력, 취소, 오류 후 정리, 출력 충돌 보존, TAR.GZ 두 단계 해제 확인. 실제 빌드 실행기의 GUI 요청 경로도 별도 확인.
- 포터블 격리 등록·이동·해제·복구·실행 검사 35개 통과. 실제 공용 설치·메뉴 등록은 변경하지 않았습니다.
- 최종 바이너리와 두 배포물의 Kaspersky 검사: 내부 포함 33개 모두 정상, 탐지·의심·오류 0. 과거 다른 빌드의 탐지에 대한 오탐 판정과는 별개입니다.
- 일반 사용자 실행과 기존 보안 검사를 유지합니다. 이번 버전에서 실제 설치·제거 순환 검사나 UAC 상승 검사는 반복하지 않았습니다. 네트워크·긴 경로·링크·일부 특수 형식에 관한 기존 제한은 README를 확인하세요.
