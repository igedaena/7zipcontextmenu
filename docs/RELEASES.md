# 0.4.1

2026-10-26. 설치형과 포터블의 기능은 같습니다.

- 기능별 ON/OFF, 바로/계단식 배치와 아이콘 옵션을 제공합니다.
- 우클릭의 설정 메뉴를 숨길 수 있습니다. 시작 메뉴와 포터블의 설정 열기로 다시 접근합니다.
- 단일 파일·폴더는 ZIP/7z 압축, 단일 압축 파일은 ZIP/7z로 감싸기, 다중 선택은 하나로 압축하기로 문구를 구분합니다. 감싸기는 형식 변환이 아닙니다.
- 관리자 권한에서 셸 DLL과 실행기의 작업을 실제 토큰 검사로 차단합니다.
- 설치·실행 시 7-Zip과 엔진의 최소 버전 26.05를 확인합니다.
- 포터블은 현재 사용자의 메뉴만 등록하며 기존 공용 설치·다른 소유자의 등록을 덮어쓰지 않습니다.
