# 아이콘

- `sevenzip-extension-source.png`: ImageGen으로 생성한 투명 PNG 원본.
- `sevenzip-extension.png`: Windows용으로 여백을 맞춘 256px 미리 보기.
- `sevenzip-extension.ico`: 16, 20, 24, 32, 40, 48, 64, 128, 256px 아이콘.

`scripts/Export-Icon.ps1`은 원본 PNG를 크기별로 변환하여 ICO와 미리 보기를 만듭니다. 메뉴 DLL, 실행기, 설정·진행 창, 설치·제거 프로그램에서 사용합니다.

7-Zip의 7z 표기를 참고한 독립 확장용 그림입니다. 참고용으로 추출한 원본 프로그램의 아이콘과 생성 프롬프트는 저장소에 포함하지 않습니다. 프로젝트 및 아이콘의 배포 라이선스는 아직 정하지 않았습니다. [외부 구성 요소 안내](../THIRD_PARTY_NOTICES.md)를 참고하세요.
